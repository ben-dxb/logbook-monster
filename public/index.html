    Read a PDF with AI

    Upload your coach's meal plan as a PDF (or a photo) and AI breaks it down into meals, foods, amounts and targets. New foods are added to the Foods list. Check everything before you save – nothing changes until you do.

    OpenRouter API key

    The AI runs through OpenRouter. Paste your key here; it is kept on the server and never shown again. Pick any OpenRouter model that reads PDFs.

    CSV format

    One row per food, with these headings in the first row: day_type, meal, meal_name, box, food, grams, locked, note. day_type is training, rest or saturday; meal is the meal number; box is protein, carbs or fats (left blank, it follows the food's swap list); food is a food id or its name from the Foods list below; locked is yes to keep that amount fixed. Day types missing from the file keep their current plan. The easiest start is to download the current plan and edit it.

    People

    Invite someone by email. They get a link to pick a password (or use Google with that address) and have their own days, history and weight. The link works once and runs out after 7 days. Invited people can sign in even if ALLOWED_EMAILS doesn’t list them.

    Email

    The email account Logbook Monster sends invites and notifications from. The password is kept on the server and never shown again.

    Using Gmail

    Gmail needs an app password, not your normal one: turn on 2-Step Verification for the Google account, then create an app password at myaccount.google.com/apppasswords and paste the 16 letters above. Server smtp.gmail.com, port 465. Outlook uses smtp.office365.com, port 587. Any other provider’s SMTP details work too.
